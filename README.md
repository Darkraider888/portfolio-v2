# ⚙️ Running Locally

No complicated setup is required.

### 1. Clone the repository

```bash
git clone https://github.com/Darkraider888/portfolio-v2.git
```

### 2. Enter the project directory

```bash
cd portfolio-v2
```

### 3. Open the project

You can open `index.html` directly in your browser.

For development, using a local server is recommended.

For example, with the **Live Server** extension in Visual Studio Code:

```text
Right-click index.html
→ Open with Live Server
```

# 🚀 Deployment

The production website is hosted on **Vercel**.

The repository contains a `vercel.json` configuration for clean URLs and basic response security headers.

After connecting the repository to Vercel, updates to the production branch can be deployed automatically.

Typical workflow:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

Then Vercel handles the production deployment.
